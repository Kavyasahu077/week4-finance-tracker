# Personal Finance Tracker

## Project Description

Personal Finance Tracker is a Python-based application developed to help users manage their daily expenses efficiently. The program allows users to add, store, search, categorize, and analyze expenses while maintaining records using file handling techniques.

This project combines Python concepts from Weeks 1–4 including:

* Functions
* Dictionaries & Lists
* File Handling
* JSON & CSV Operations
* Error Handling
* Modular Programming

The application provides a simple command-line interface that makes expense tracking easy and organized.

# Features

* Add new expenses with validation
* Categorize expenses (Food, Bills, Transport, Entertainment, etc.)
* Store data permanently using JSON files
* Load saved expenses automatically
* Search expenses by category or keyword
* Generate monthly expense reports
* Display category-wise expense breakdown
* Export expense data to CSV format
* Backup and restore expense data
* User-friendly menu system
* Error handling for invalid inputs

# How to Run the Program

## Step 1

Make sure Python is installed on your system.

Check using:

python --version

## Step 2

Open the project folder in VS Code.

## Step 3

Open terminal in VS Code.

Shortcut:

Ctrl + `

## Step 4

Navigate to the project folder:

cd week4-finance-tracker

## Step 5

Run the application:

python run.py

# Technical Details

## Data Structure Used

Expenses are stored as dictionaries inside lists.

Example:

expense = {
"amount": 250,
"category": "Food",
"description": "Pizza"
}

## File Handling

* JSON files are used for permanent data storage
* CSV files are used for exporting reports
* Backup files help recover data if needed

## Error Handling

The project uses:

* try-except
* Input validation
* File existence checks

to prevent crashes and invalid data entry.
