# Personal Finance Tracker

## Project Description

Personal Finance Tracker is a Python-based application that helps users manage and track daily expenses.

The system stores expenses in JSON files and generates expense statistics category-wise.

This project combines concepts from Python fundamentals including:
- Functions
- File Handling
- Classes & Objects
- Modules
- JSON Handling
- Error Handling

---

# Features

- Add new expenses
- Save expenses to JSON file
- Load saved expenses automatically
- View all expenses
- Generate category-wise reports
- Menu-driven interface
- Input validation
- Modular project structure
